# Creational Patterns

Creational patterns are about **object creation mechanisms**. They abstract the instantiation process, making it easier to create objects in a way that suits the situation — hiding the complexity of how, when, and which objects are created.

Common examples include **Singleton**, **Factory Method**, **Abstract Factory**, and **Builder**. These patterns are especially helpful when the exact type of object to create isn't known until runtime, or when you want to enforce constraints on how many instances of a class can exist.
