# Structural Patterns

Structural patterns deal with **how classes and objects are composed** to form larger structures. They use inheritance and composition to let you build flexible, efficient object graphs without tightly coupling the parts together.

Common examples include **Adapter**, **Decorator**, **Facade**, and **Composite**. These patterns are particularly useful when integrating incompatible interfaces, adding responsibilities to objects dynamically, or simplifying complex subsystems behind a clean API.
